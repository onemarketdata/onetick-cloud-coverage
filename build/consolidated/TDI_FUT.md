# Global Futures

A curated list of more than 280 of the most liquid global futures contracts traded across 25+ markets, with history back to December 1974. Contracts span equity indices, interest rates, government bonds, currencies, energy, metals and agriculture, and bars are available, making it suited to long-horizon research and cross-asset backtesting from a single database.

Consists of 3 Databases

* `TDI_FUT_BARS`  - 1 Minute Bars
* `TDI_FUT_DAILY`  - End of Day Metrics




## TDI_FUT

Database includes the following tick types:

* DAY - Daily price and statistical data, e.g. closing price, settlement price, open interest
* QTE - Best bid / offer quotes
* STAT - Static data, e.g. ISIN, description, security type
* TRD - Trades





## TDI_FUT_BARS

Database includes the following tick types:

* DAY - Daily price and statistical data, e.g. closing price, settlement price, open interest
* QTE_1M - 1-minute quote bars
* TRD_1M - 1-minute trade bars





## TDI_FUT_DAILY

Database includes the following tick types:

* DAY - Daily price and statistical data, e.g. closing price, settlement price, open interest
* STAT - Static data, e.g. ISIN, description, security type
