# OQD - One Quant Data

Reference Data to populate a Security Master, including Daily Price History, Corporate Actions history, Market Calendar and Symbology mapping

It covers:

* [OQD_CACT](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_CACT.html.md) - Global Corporate Actions History
* [OQD_DPRC](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_DPRC.html.md) - Daily Price History for Global Equities
* [OQD_ETF](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_ETF.html.md) - US ETF Constituents
* [OQD_FUT](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_FUT.html.md) - Daily Price History for Global Futures
* [OQD_MKTCAL](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_MKTCAL.html.md) - Historic Market Holiday Calendar and Trading Hours
* [OQD_SEC](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_SEC.html.md) - Instrument Security Master
* [OQD_XOID](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_XOID.html.md) - Instrument Symbology Cross Reference from OID
* [OQD_XSYM](https://cloudcoverage.docs.sol.onetick.com/oqd/OQD_XSYM.html.md) - Instrument Symbology Cross Reference to OID
